# Schema 3.0.3 usage

No profiler-hub writer supports schema 3.0.3.

`writer_t` throws `std::invalid_argument` before it creates the database.
Supported writer versions are 3.0.0 and 3.0.1. See `docs/schema/3.0.1_usage.md`.

3.0.3 adds `sample_id`, `xcc`, `shader_engine`, and `instance` on
`rocpd_pmc_event`. The writer does not insert those columns.
