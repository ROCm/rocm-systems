# Schema 3.0.5 Usage Guide

Validation errors for schema 3.0.5 point here. This page lists the fields
`pmc_event_input_t` may set when the selected schema is 3.0.5.

The C++ struct is a superset: it carries every `rocpd_pmc_event` column a caller
can set in 3.0.0 through 3.0.5. Schema 3.0.5 does not accept every member.
`schema_validator::validate()` rejects a member that is set and absent from
this version.

Table: `rocpd_pmc_event`. Validation reports the object as `PMCEvent`.

SQLite assigns `id` and `guid`. They are not members of the struct.

## Structure

```cpp
struct pmc_event_input_t
{
    std::optional<int64_t>     event_id;
    std::optional<int64_t>     sample_id;
    std::optional<int64_t>     pmc_id;
    std::optional<double>      value;
    std::optional<int>         xcc;
    std::optional<int>         shader_engine;
    std::optional<int>         instance;
    std::optional<std::string> extdata;
};
```

An empty `std::optional` means the caller did not set that field. Zero is a
real value and is checked like any other set field.

## Supported fields

| Field      | Required | Description                                                                 |
|------------|----------|-----------------------------------------------------------------------------|
| `pmc_id`   | Yes      | Counter row in `rocpd_info_pmc`. `NOT NULL`, no default.                    |
| `event_id` | No       | Event row in `rocpd_event`. Null when this sample has no event.             |
| `sample_id`| No       | Sample row in `rocpd_sample`. Null for a PMC sample. Set for an SPM sample. |
| `value`    | No       | Counter value (`REAL`). Defaults to `0.0` when omitted.                     |
| `extdata`  | No       | Extra JSON payload. Defaults to `{}` when omitted.                          |

## Fields this version rejects

These members are on the struct because schema 3.0.3 and 3.0.4 stored them on
`rocpd_pmc_event`. Schema 3.0.5 moved them to `rocpd_info_pmc`. Setting any of
them on `pmc_event_input_t` fails validation for 3.0.5.

| Field           | Where it lives in 3.0.5                                      |
|-----------------|--------------------------------------------------------------|
| `xcc`           | `rocpd_info_pmc.xcc`                                         |
| `shader_engine` | `rocpd_info_pmc.shader_engine`                               |
| `instance`      | `rocpd_info_pmc.instance`                                    |

`shader_array` and `wgp` were never columns of `rocpd_pmc_event`. In 3.0.5 they
are on `rocpd_info_pmc` only, and they are not members of this struct.

## Example

`pmc_id` has to be set. `sample_id` is allowed and may be left unset for a PMC
sample.

```cpp
profiler_hub::schema::pmc_event_input_t event;

event.pmc_id    = 1;
event.sample_id = 100;
event.value     = 1.5;

auto result = profiler_hub::schema::schema_validator::validate(
    event, profiler_hub::version_t{ 3, 0, 5 });
```

## Rejected example

```cpp
profiler_hub::schema::pmc_event_input_t event;

event.pmc_id = 1;
event.xcc    = 0;
```

```text
Validation Failed

Schema:
    3.0.5

Object:
    PMCEvent

Field:
    xcc

Reason:
    Field is not supported
    by schema version 3.0.5

Documentation:
    docs/schema/3.0.5_usage.md
```

Put `xcc` on the `rocpd_info_pmc` row that `pmc_id` points at, and leave it
unset on the event.
