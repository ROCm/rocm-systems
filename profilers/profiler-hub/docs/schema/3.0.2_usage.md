# Schema 3.0.2 usage

No profiler-hub writer supports schema 3.0.2.

`writer_t` throws `std::invalid_argument` before it creates the database.
The message is:

```
No writer is supported
for schema version 3.0.2.
Supported writer versions:
3.0.0
3.0.1
```

3.0.2 added `graph_exec_id`, `graph_node_id`, and `rocpd_graph_launch`. The
schema_v3 writer still inserts the 3.0.1 column list, so it refuses the
version instead of leaving those columns empty.

Use schema 3.0.1. See `docs/schema/3.0.1_usage.md`.
