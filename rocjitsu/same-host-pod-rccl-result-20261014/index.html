    Same-host pod RCCL qualification, 2026-10-14¶

    This historical run passed the original same-host gate in both QEMU/VFIO and emulated KFD mode. The revised gate prohibits the nonstandard QEMU/libvfio-user peer transport used by the VFIO run, so this record no longer qualifies the VFIO mode under the current criteria. The emulated KFD result remains valid for that mode. This result was produced from checkout 07988db4b20d25ddf8cab50a008791255ec96532 with uncommitted working-tree changes. No commit was created.     Topology and driver path¶

    configs/gfx1250_mi455x_kmd_4node_2gpu_if.json (SHA-256 c14b21b6df774e9fddcba59c93f0c27f5063dcd086d39f38b360bdb0994fcd22) defines four nodes. Their GPU IDs are (1250,1251), (1252,1253), (1254,1255), and (1256,1257). Each pair reaches a node-local Simdojo Infinity Fabric switch through modeled GPU endpoints. Separate net0 through net3 endpoints describe inter-node reachability; no GPU peer request uses a NIC link. Four independent QEMU guests each expose two PCI GPUs and one NIC. The guest NICs used 10.77.0.1 through 10.77.0.4 on QEMU socket multicast segment 239.192.14.1:57550. Four isolated emulated KFD daemons project the same node pairs, use separate runtime directories and NCCL_HOSTID values, and connect cross-node Socket traffic over host loopback.

    The pinned gfx1250 A0 AMDGPU/AMDKFD driver uses its ordinary PCIe peer BAR mapping with a UC peer PTE. RCCL selected P2P/IPC for local ranks and NET/Socket for remote ranks. Local peer effects crossed the modeled Infinity Fabric route behind the supported PCIe mapping. This is not evidence of a native xGMI discovery or mapping path; the link class and hive_id alone do not establish native xGMI. The emulated run set the public ROCr HSA_ENABLE_IPC_MODE_LEGACY=1 option. The default ROCr IPC mode is not qualified by this record.

    The guest amdgpu.ko was built from amdgpu-dkms_7.1.3.31500000-2390945.24.04_all.deb with the driver bug-fix patches 0001 through 0008 in numeric order. Optional diagnostic patch 0011 was not applied. Omitted historical experimental guest patches were also absent. These local patches are no longer included in this repository. The module inside the final guest image is the staged override described here; the older base-image-lock.json records the source image, not the final module hash. The guest kernel was 6.17.0-23-generic. QEMU came from pinned revision f8b2f64e2336a28bf0d50b6ef8a7d8c013e9bcf3 with a nonstandard peer transport, PCIe AtomicOp capability, and XIO3130 LinkCap fixes. These host/QEMU changes added no guest-driver protocol. The nonstandard transport is disallowed by the revised gate. The numerical and route evidence below must not be presented as a stock-QEMU/libvfio-user qualification.

    Exact controller commands¶

    Both controllers used an 1800-second overall deadline. The guest used TCG, four vCPUs, 12 GiB RAM, two VFIO-user sockets per node, the kernel arguments and environment recorded in the VFIO result JSON, and eth0 for NET. The emulated controller used four daemons, separate runtime directories, the standard ROCr legacy IPC option, and lo for NET.

    python3 scripts/run-rccl-pod-vfio.py \
  --qemu tmp/p2v-qemu-v2-build/qemu-system-x86_64 \
  --kernel tmp/p3v-guest-coherent-trial/vmlinuz \
  --initramfs tmp/same-host-pod-20261014/initramfs-final.gz \
  --rocjitsu tmp/p3v-alias-observation-release/tools/rocjitsu/rocjitsu \
  --config configs/gfx1250_mi455x_kmd_4node_2gpu_if.json \
  --driver-module tmp/same-host-pod-20261014/root/modules/amdgpu.ko \
  --driver-package tmp/amdgpu-dkms_7.1.3.31500000-2390945.24.04_all.deb \
  --rank-binary tmp/p3v-alias-observation-release/tests/hip_rccl_gfx1250_test \
  --output /tmp/rj-pod-vfio-20261014-run5 --timeout 1800

    Each mode used one eight-rank communicator, two ranks per node, seed 79, ROCR_VISIBLE_DEVICES=0 or 1 per rank, 64 and 262144 float elements, and three iterations at each size for AllReduce, Broadcast, AllGather, ReduceScatter, and SendRecv. The rank binary calculated host-side references and compared every GPU result. All 16 rank/size executions in each mode passed all five cases against tolerance-based numerical references. AllReduce logged explicit zero mismatches. The verifier infers its zero-mismatch summary for the other cases from passing checks and no nonzero diagnostics; their logs do not provide per-case mismatch counts. The controller also required P2P/IPC and NET/Socket channels in each rank/size log; a NET-only run would fail.

All ranks, guest launchers, and emulated node helpers completed within their bounds. Every QEMU guest reported its two AMDGPU-bound devices, numerical result=PASS, and orderly poweroff. The four QEMU launchers and four emulated helpers exited zero. No VFIO-user or emulated daemon sockets remained.

    FabricEndpoint* passed 37 focused tests, including the prepared-maintenance retry and one-commit regression. A serial CTest selection for fabric, VFIO, PCI, VM, KFD, cache, MES, and queue components passed all 430 tests; the output is evidence/rj-pod-regressions-20261014.log.
