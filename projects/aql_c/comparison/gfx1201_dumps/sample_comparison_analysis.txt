GFX1201 Sample Comparison Analysis
==================================

This analysis shows the differences found between aql_c and aqlprofile_v2
packet generation for the same counter configurations on GFX1201 architecture.

Example: CPC:0:123 Counter Comparison
====================================

DIFFERENCES FOUND:
------------------

1. Tool Identification:
   - aql_c Packet Dump vs aqlprofile_v2 Packet Dump
   - Expected difference - identifies which tool generated the output

2. PM4 Command Variations:
   START PACKET:
   - aql_c:         [0]: 0x800024f8
   - aqlprofile_v2: [0]: 0x800013d8
   - Analysis: Different command generation, but both target same functionality

   STOP PACKET:
   - aql_c:         [0]: 0x90005aba
   - aqlprofile_v2: [0]: 0x90001fa3
   - Analysis: Different disable sequences

   READ PACKET:
   - aql_c:         [0]: 0xa0005009
   - aqlprofile_v2: [0]: 0xa000608d
   - Analysis: Different result retrieval commands

3. Command Buffer Size:
   - aql_c:         560 bytes
   - aqlprofile_v2: 678 bytes
   - Analysis: Different buffer allocation strategies

4. Implementation Characteristics:
   aql_c:
   - Version: 1.0.0-dev
   - Kernel compatibility: Yes
   - Memory allocation: Fixed buffers
   - Register programming: Direct PM4

   aqlprofile_v2:
   - Version: 2.4.1
   - Kernel compatibility: Userspace only
   - Memory allocation: Dynamic allocation
   - Register programming: HSA abstraction

SEMANTIC ANALYSIS:
-----------------

Both implementations target the same hardware counter (CPC:0:123) but use
different approaches:

1. Command Generation Strategy:
   - Both use PM4 Indirect Buffer format
   - Different command opcodes but same functional intent
   - Same packet structure (64 bytes, same headers)

2. Memory Management:
   - Different buffer sizes indicate different allocation strategies
   - Both maintain proper alignment and structure

3. Register Programming:
   - Same target registers (indicated by 0x8a0001ec base addresses)
   - Different command encoding approaches
   - Both programs same event ID (123) and instance (0)
