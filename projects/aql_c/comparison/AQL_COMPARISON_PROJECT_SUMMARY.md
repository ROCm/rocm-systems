# AQL Packet Comparison Project Summary

## Project Overview

This project provides comprehensive tools and documentation for comparing AQL packets generated by two different implementations:

1. **aql_c**: A C-based kernel-compatible port of AQLProfile functionality
2. **aqlprofile_v2**: The existing AQLProfile v2 implementation

## Deliverables Created

### 📚 Documentation Files

1. **`comparison_methodology.md`** - Detailed comparison methodology covering:
   - Test case design strategies
   - Packet extraction and analysis techniques
   - Output format specifications
   - Quality assurance procedures
   - Integration with development workflows

2. **`aql_c_interface_documentation.md`** - Complete API reference for aql_c library:
   - Core data types and structures
   - Architecture support (GFX9, GFX10, GFX11, GFX12)
   - Command buffer management
   - Counter configuration
   - AQLProfile v2-compatible interface
   - Usage examples and best practices

3. **`rocprofiler_sdk_counter_usage.md`** - Integration guide for ROCProfiler SDK:
   - Counter configuration and management
   - Internal packet construction flow
   - Memory management strategies
   - Data collection and processing
   - Architecture-specific considerations

4. **`aqlprofile_v2_interface.md`** - Detailed reference for AQLProfile v2 API:
   - Agent management and registration
   - Performance counter interface
   - AQL packet creation
   - Data collection mechanisms
   - Thread trace support
   - Complete usage examples

### 🛠️ Comparison Tools

1. **`aql_c_dumper.c`** - AQL_C packet dumper program:
   - Command-line interface for counter specification
   - Multiple output formats (JSON, binary, text)
   - Architecture detection and validation
   - Detailed packet structure dumping
   - Memory allocation tracking

2. **`aqlprofile_v2_dumper.c`** - AQLProfile v2 packet dumper:
   - Identical interface to aql_c_dumper
   - Same output formats for direct comparison
   - Agent registration and validation
   - Event validation and error handling

3. **`packet_compare.py`** - Python comparison tool:
   - Binary and semantic comparison modes
   - JSON and binary format support
   - Detailed difference reporting
   - Batch comparison for test suites
   - Visual diff output with highlighting

4. **`run_comparison_tests.sh`** - Automated test runner:
   - Multiple test suites (basic, full, stress)
   - Parallel test execution
   - Architecture-specific testing
   - Automated report generation
   - Integration with CI/CD systems

5. **`Makefile`** - Build system:
   - Builds all comparison tools
   - Dependency checking
   - Test automation targets
   - Installation support
   - Debug and development targets

## Quick Start Guide

### Prerequisites
- C compiler (gcc/clang)
- Python 3.x
- ROCm installation
- Built aql_c_port and aqlprofile projects

### Building and Testing
```bash
# Build all tools
make all

# Run basic comparison tests
make test

# Run comprehensive tests
make test-full

# Manual comparison example
./aql_c_dumper --arch gfx942 --counter CPC:0:123 --output test.json
./aqlprofile_v2_dumper --arch gfx942 --counter CPC:0:123 --output ref.json
./packet_compare.py test.json ref.json --detailed
```

## Expected Results

### ✅ Perfect Compatibility Indicators
- Identical packet structures
- Same PM4 command sequences
- Equivalent memory allocation patterns
- Consistent counter programming

### ⚠️ Acceptable Differences
- Different memory addresses (same relative layout)
- Alternative but equivalent PM4 sequences
- Architecture-specific optimizations

### ❌ Problematic Differences (Require Investigation)
- Missing or extra PM4 commands
- Incorrect register programming
- Wrong counter block assignments
- Memory allocation size mismatches
