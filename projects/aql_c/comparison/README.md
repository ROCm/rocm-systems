# AQL Packet Comparison Tools

This directory contains tools and documentation for comparing AQL packets generated by aql_c and aqlprofile_v2 implementations.

## Files Overview

### 📚 Documentation
- **`AQL_COMPARISON_PROJECT_SUMMARY.md`** - Complete project overview and usage guide
- **`comparison_methodology.md`** - Detailed comparison methodology and best practices
- **`aql_c_interface_documentation.md`** - AQL_C API reference and usage guide
- **`rocprofiler_sdk_counter_usage.md`** - ROCProfiler SDK integration documentation
- **`aqlprofile_v2_interface.md`** - AQLProfile v2 API reference

### 🛠️ Tools
- **`aql_c_dumper.c`** - AQL_C packet dumper program
- **`aqlprofile_v2_dumper.c`** - AQLProfile v2 packet dumper program
- **`packet_compare.py`** - Python packet comparison tool
- **`run_comparison_tests.sh`** - Automated test runner script
- **`Makefile`** - Build system for all tools

## Quick Start

```bash
# Build all tools
make all

# Run basic comparison test
make test

# Manual comparison example
./aql_c_dumper --arch gfx942 --counter CPC:0:123 --output test.json
./aqlprofile_v2_dumper --arch gfx942 --counter CPC:0:123 --output ref.json
./packet_compare.py test.json ref.json --detailed
```

## Documentation Reading Order

1. Start with **`AQL_COMPARISON_PROJECT_SUMMARY.md`** for project overview
2. Read **`comparison_methodology.md`** for testing approach
3. Review API documentation as needed:
   - **`aql_c_interface_documentation.md`** for aql_c usage
   - **`aqlprofile_v2_interface.md`** for aqlprofile_v2 usage
   - **`rocprofiler_sdk_counter_usage.md`** for ROCProfiler integration

## Tool Usage Flow

1. **Build**: `make all`
2. **Test**: `make test` or `./run_comparison_tests.sh`
3. **Compare**: Use dumpers + comparison tool for detailed analysis
4. **Analyze**: Review differences and validate compatibility

For detailed usage instructions, see the project summary document.
