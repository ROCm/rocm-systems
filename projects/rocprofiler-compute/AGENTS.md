# Agent instructions (rocprofiler-compute)

Used by tools that read **`AGENTS.md`** at the project root (including **OpenAI Codex** and **OpenCode**). Canonical content still lives under **`.ai/`** — this file is the entry point.

This repository’s **canonical AI rules** live under [`.ai/`](.ai/README.md).

Before making changes:

1. Read [`.ai/rules/core.md`](.ai/rules/core.md) (and [`.ai/rules/anti_patterns.md`](.ai/rules/anti_patterns.md) when editing behavior).
2. Use the prompt in [`.ai/prompts/default.md`](.ai/prompts/default.md) or summarize it in your first message.
3. Pick one skill from [`.ai/skills/index.md`](.ai/skills/index.md).
4. Follow [`.ai/standards/`](.ai/standards/) for Python, C++, or CMake as applicable.

Contributors: see also [docs/AI_GUIDE.md](docs/AI_GUIDE.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
