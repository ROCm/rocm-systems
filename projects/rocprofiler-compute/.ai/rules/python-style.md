# Python Coding Style

The Python style guide for this project lives in **[`PYTHON_CODING_STYLE.md`](../../PYTHON_CODING_STYLE.md)**. Each section there has a `### Rules` subsection with the imperative, AI-authoritative rules alongside the rationale and worked examples.

When generating or modifying Python code, read the `### Rules` subsection of the relevant section before writing.

Before adding or modifying test code, read **[`Testing Conventions`](../../PYTHON_CODING_STYLE.md#testing-conventions)** to understand how testing code is maintained.
