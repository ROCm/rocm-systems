# AMD SMI C/C++ constants

This page documents the public enumerations and constant definitions available
in the AMD SMI C/C++ API.

## Enumerations

These enums define AMD SMI status codes, initialization flags, and other API
values, such as hardware types, event types, and state identifiers.

```{amdsmi-doxygen}
:kind: enums
```

## Limits and sizes

These `#define` constants specify public limits, buffer sizes, semantic version
information, and other fixed API values used by AMD SMI.

```{amdsmi-doxygen}
:kind: defines
```
