# AMD SMI C/C++ typedefs

These type definitions are exposed by `amdsmi.h` and include opaque handles
(used to reference processors and sockets), semantic type aliases for structs
and enums, and other type aliases used throughout the AMD SMI API. For usage
information and best practices, see [](../../how-to/amdsmi-cpp-lib.md).
