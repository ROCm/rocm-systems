********************************************************************
rocDecode samples
********************************************************************

rocDecode samples are available in the `rocDecode GitHub repository <https://github.com/ROCm/rocm-systems/tree/develop/projects/rocdecode/samples>`_.

FFmpeg development libraries must be installed to build and run samples:

.. code:: shell

  sudo apt install libavcodec-dev libavformat-dev libavutil-dev

Walkthroughs of the :doc:`videodecode.cpp <../how-to/using-rocDecode-videodecode-sample>` and :doc:`rocdecdecoder.cpp sample <../how-to/using-rocDecode-rocdecdecoder>` samples are available.
