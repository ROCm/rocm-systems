* Multi-segment buffers (a VA range backed by several VMM allocations) are registered only when `NCCL_MULTI_SEGMENT_REGISTER=1`, DMA-BUF is enabled and the communicator's network or RMA plugin registers one memory region per physical segment; no current plugin does yet. With other plugins, a multi-segment buffer passed to network user-buffer registration is staged instead of registered through a DMA-BUF that covered only the first segment, and a symmetric window that cannot be registered for RMA returns `ncclInvalidUsage` on an RMA put instead of using a missing registration; the hierarchical CE collective falls back to another algorithm for such a window. With `NCCL_SYM_REUSE_SYSMEM_HANDLES=1`, GIN registers a host segment through its owner's fd (the creating rank's own fd, or the single host owner's fd on the other ranks), and a rank that fails to obtain that fd fails the window on every rank.
