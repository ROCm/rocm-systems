* Multi-segment buffers (a VA range backed by several VMM allocations) are registered only with `NCCL_MULTI_SEGMENT_REGISTER=1`, DMA-BUF enabled and a network or RMA plugin that registers one memory region per segment; no plugin in this change does. Otherwise network user-buffer registration stages such a buffer and RMA registration skips such a symmetric window, as it also does when ranks have different segment counts, a rank has more than 1024 segments, or ranks times segments exceeds 2^20. An RMA put on a window without an RMA registration fails with `ncclInvalidUsage` at launch, not at the `ncclPut` call. With `NCCL_SYM_REUSE_SYSMEM_HANDLES=1`, GIN registers a host segment through its owner's fd.
