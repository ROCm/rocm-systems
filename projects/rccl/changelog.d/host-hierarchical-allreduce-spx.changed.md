* `RCCL_HOST_HIER_ALLREDUCE`: the default (`-1`) now also uses host-hierarchical AllReduce for FP32 `ncclSum` on gfx1250 hosts with four ranks each when every GPU reports the SPX partition mode: 64 to 512 MiB on eight hosts. On four hosts and below 64 MiB, the default path was faster. `RCCL_HOST_HIER_ALLREDUCE_FUSED` now picks the fused kernel automatically only with eight ranks per host.
