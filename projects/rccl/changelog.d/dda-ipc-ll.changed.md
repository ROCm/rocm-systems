* gfx950 and gfx942 single-node 8-rank `ncclAllReduce` up to 4 KiB and `ncclReduceScatter` up to 32 KiB run the DDA LL one-shot in the IPC LL region, with no GPU barrier and no staging copy, on no more blocks than the DDA IPC kernel they replace. On these comms `RCCL_DDA_LL_THRESHOLD` now also sets both ceilings when `RCCL_DDA_IPC_LL_THRESHOLD` is unset, `RCCL_DDA_LL=0` turns the one-shot off, and `RCCL_DDA_THRESHOLD=0` no longer keeps these sizes off DDA. `RCCL_IGNORE_ARCH_TABLE=1` keeps the one-shot; set `RCCL_DDA_IPC_LL_THRESHOLD=0` to run the previous path.
