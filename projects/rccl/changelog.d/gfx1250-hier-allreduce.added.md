* Added the hierarchical symmetric AllReduce kernel `AllReduce_HierLsaLDST` for gfx1250 partitioned communicators. Where it can run, symmetric `ncclAllReduce` selects it unless `NCCL_SYM_KERNEL` forces another kernel. `NCCL_SYM_HIER_PIPELINE` (default `-1`, size schedule) sets whether it splits its warps into concurrent roles (`1`) or runs every role on all warps in turn (`0`). All ranks must set the same value; on a partitioned communicator, initialization fails with `ncclInvalidUsage` when they do not.
