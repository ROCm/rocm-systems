* On gfx950 with the legacy IPC P2P path (`NCCL_CUMEM_ENABLE=0`), a communicator created after an earlier one was destroyed in the same process could return wrong AllReduce data: a receive buffer that reused memory a freed cacheable allocation had written could return that old data to its owning GPU. The owning GPU now reads every cache line of each new legacy IPC P2P buffer once, right after it is zeroed and before it is exported, which prevents this. Controlled by `RCCL_P2P_PRIME` (internal; default `-1` = on for gfx950 only, `0` = off, `1` = on for every architecture).
