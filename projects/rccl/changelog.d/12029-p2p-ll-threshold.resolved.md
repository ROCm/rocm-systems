* Fixed P2P protocol selection on single-node all-XGMI gfx942 and gfx950. The NCCL 2.29 channel estimate counted SIMPLE channels, which is 1 below 64 KiB per peer, so the 4 KiB `NCCL_P2P_LL_THRESHOLD` never selected legacy LL and transfers in that range lost the low-latency path. With the variable unset or empty, legacy LL is now used up to the smaller of the SIMPLE part size (`NCCL_P2P_NVL_CHUNKSIZE / 8`, 64 KiB by default) and 64 KiB per peer. A non-empty `NCCL_P2P_LL_THRESHOLD` still uses the per-channel rule, and the LL128 path is unchanged. Other architectures, PCIe-only pairs, and multi-node communicators are unchanged.
