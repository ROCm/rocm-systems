* Fixed a system-scope fence on every fused addon stop event. After the addon launch ordering change, the last kernel carried `comm->doneEvent`, which HIP treats as a system-scope release when used as a ExtLaunch stop event. Addon launches now fuse a separate event created with `hipEventDisableSystemFence`; a collective on another stream waits on whichever event the previous collective recorded. Hierarchical AllGather (for example 8 nodes / 64 GPUs) and single-node DDA IPC ReduceScatter and AllToAll benefit. The Begin/End bracket, stop-event take and graph-capture ordering are unchanged.
