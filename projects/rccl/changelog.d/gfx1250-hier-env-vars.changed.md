* `NCCL_SYM_HIER_CTAS` and `NCCL_SYM_HIER_CHUNK_BYTES` replace `NCCL_SYM_AG_HIER_CTAS` and `NCCL_SYM_AG_HIER_CHUNK_BYTES` and apply to every hierarchical LSA kernel: `AllGather_HierLsaST`, `AllGather_HierLsaTmaST`, `ReduceScatter_HierLsaLDST` and `AllReduce_HierLsaLDST`. `NCCL_SYM_HIER_CTAS` (default `0`, each kernel's size schedule) sets the block count for every size, clamped to `MAXCHANNELS`, and the TDM AllGather never exceeds 48; the communicator sizes the kernels' flags and slots for it when it is created. `NCCL_SYM_HIER_CHUNK_BYTES` (default `0`, each kernel's default) caps the AllGather's pushed chunk, clamped to 1 GiB, and sets the bytes a ReduceScatter or AllReduce block sends each other package per round, capped at what the slots hold. All ranks must set the same values; on a partitioned communicator, initialization fails with `ncclInvalidUsage` when they do not.
