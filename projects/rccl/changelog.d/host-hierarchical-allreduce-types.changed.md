* `RCCL_HOST_HIER_ALLREDUCE`: the default (`-1`) now uses host-hierarchical AllReduce for more datatypes and operations on gfx1250, at the same message sizes as FP32 `ncclSum`. With eight ranks per host (DPX), `ncclSum` on FP16 and BF16 is now also used on four and eight hosts, and `ncclSum` on FP8 on two, four and eight hosts. With four ranks per host (SPX), `ncclSum` is used on every type, `ncclProd` on every type except FP8, `ncclMax` and `ncclMin` on every type except FP8, `ncclInt8` and `ncclUint8`, and `ncclAvg` on FP16, FP32, FP64 and BF16.
