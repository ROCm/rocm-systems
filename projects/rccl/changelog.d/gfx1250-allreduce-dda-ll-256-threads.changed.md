* On gfx1250, `ncclAllReduce` DDA LL one-shot and two-shot run 256-thread blocks (previously 512 and 1024; two-shot above 8 MiB keeps 1024). The spread two-shot keeps 512 threads and is chosen against the 256-thread one-shot block, so 16-rank messages of 4-64 KiB now run the one-shot instead. On SPX, comms below 8 ranks run the LL two-shot up to nRanks x 1 MiB (4 MiB on 4 ranks, previously DDA LL128 above 2 MiB).
