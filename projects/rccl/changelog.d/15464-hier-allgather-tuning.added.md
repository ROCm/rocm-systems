* `NCCL_SYM_AG_HIER_CTAS` (default `0`): block count for `AllGather_HierLsaST`. `0` uses 64 blocks when the gathered size is below 1 GiB and 72 from 1 GiB up, raised to `NCCL_MIN_CTAS` when that is higher. A positive value uses that count for every size, clamped to `MAXCHANNELS`. `NCCL_SYM_CTAS`, when set, is used instead, capped at this limit. The launch can still drop blocks that do not fill a package group. All ranks must set the same value; on a partitioned communicator, initialization fails when they do not.
* `NCCL_SYM_AG_HIER_CHUNK_BYTES` (default `0`): largest chunk one block of `AllGather_HierLsaST` or `AllGather_HierLsaTmaST` pushes. `0` uses 256 KiB. A positive value replaces that, clamped to 1 GiB, and is read once when the communicator is created. All ranks must set the same value; on a partitioned communicator, initialization fails when they do not.
