* Fixed a segmentation fault in `ncclCommSplit` and `ncclCommShrink` when the child shares the parent's resources (`splitShare` or `shrinkShare`), sets `netName` in its config, and the parent has no `netName` (none in its config and `NCCL_NET` unset). The child's `netName` is now checked against the network the parent uses, and a mismatch returns `ncclInvalidUsage` as it already did for a parent with a `netName`.
