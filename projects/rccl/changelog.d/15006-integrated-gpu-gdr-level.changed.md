* On gfx1170 and gfx1171 integrated GPUs (APUs), GPU Direct RDMA is now allowed by default for a NIC up to `PHB` distance instead of `PXB`. The GPU sits on the CPU root complex, so every NIC is at least `PHB` away and was previously always refused GPU Direct RDMA; its memory is system memory, so there is no peer PCIe traffic for the `PXB` limit to avoid. The topology marks integrated GPUs with an `integrated="1"` attribute (from `hipDeviceAttributeIntegrated`), which discrete GPUs do not get. Other integrated GPUs, such as gfx1151, keep the `PXB` default and can opt in with `NCCL_NET_GDR_LEVEL=PHB`. A NIC on another socket (`SYS`) is still refused, and `NCCL_NET_GDR_LEVEL` still overrides the default.
