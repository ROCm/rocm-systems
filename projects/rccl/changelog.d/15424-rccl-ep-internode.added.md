* `rccl_ep` internode dispatch and combine: a group spanning several nodes keeps load/store access within each node and reaches the other nodes with `ncclSend`/`ncclRecv`, so any RCCL network transport works. It is opt-in: the Python `ElasticBuffer` takes it only when every rank passes `allow_internode=True`, and refuses a group spanning nodes otherwise. New C entry points `ep_create_nodes`, `ep_inter_counts` and `ep_inter_bind`; up to 64 ranks, 16 per node and 16 nodes.
