* `RCCL_DDA_LL128_RS_THREADS` now defaults to `0`, which reads the arch table: the gfx1250 DDA LL128 `ncclReduceScatter` runs 256 threads per block on every partition but DPX, and 512 where the table sets none. It overrides the table with a multiple of 32 up to 512 (it defaulted to `1024` before). The kernel's 512-thread launch bound now applies, and it sends to and polls 8 peers per batch (fp8 polls 4).
