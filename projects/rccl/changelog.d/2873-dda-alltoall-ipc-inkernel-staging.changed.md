* Changed single-node DDA IPC `ncclAlltoAll` to stage sends of 4 MiB or less inside the kernel instead of a host `cudaMemcpyAsync` before the peer exchange. A one-block launch keeps a flat copy; multi-block launches use a block-matched chunked copy so each block's index set is ready after the barrier. Above 4 MiB the host pre-copy remains. This removes a same-stream blit ahead of the fused addon stop event for totals from 64 KiB through 4 MiB on 8 ranks.
