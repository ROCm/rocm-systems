* Fixed an AlltoAll bandwidth regression on MI300X (gfx942) with `RCCL_P2P_BATCH_ENABLE=1` and `RCCL_P2P_BATCH_THRESHOLD` unset, seen at 512 MiB to 2 GiB on 8 nodes. Leaving `RCCL_P2P_BATCH_THRESHOLD` unset had removed the fusion size limit everywhere except gfx950 at 16 or more nodes, so peer rounds of several MiB were fused into one work batch. On gfx942 the unset default is now 1 MiB per peer. gfx950 at 16 or more nodes keeps 64 KiB, other architectures keep no limit, and a non-negative `RCCL_P2P_BATCH_THRESHOLD` still sets the limit on every architecture.
