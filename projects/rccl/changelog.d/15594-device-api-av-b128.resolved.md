* Fixed device code built from RCCL's device API headers failing to compile in upstream-LLVM toolchains such as Triton (`Unknown type!`). The GIN proxy descriptor store, the LL all-to-all and flow LL/LL128 FIFO accesses, and the 128-bit helpers in `hip_compat.h` now use `__builtin_amdgcn_av_store_b128` / `av_load_b128` when the compiler provides them, instead of the AMD-LLVM-only `__builtin_amdgcn_global_store_b128` / `global_load_b128`. Both produce the same instructions on gfx942, gfx950 and gfx1250.
