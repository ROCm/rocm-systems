* On HIP, `NCCL_MULTI_SEGMENT_REGISTER=1` selects `IB-MSEG`, a separate copy of the IB transport for multi-segment support, and its RMA backend in place of the internal IB plugin; a request for `IB` is served by `IB-MSEG`, while `NCCL_NET=IB-CAST`, `ROCM-IB` and AINIC autodetection keep IB-CAST unless `NCCL_NET_PLUGIN` names an external plugin. `IB-MSEG` reads the same `NCCL_IB_*` and `RCCL_IB_*` variables as IB. `NCCL_NET=IB-MSEG` is a temporary developer selector that will be removed when the code moves back into the IB plugin. While `IB-MSEG` is selected, RAS reports link speed from the device properties and the active network bandwidth diagnostic does not run.
