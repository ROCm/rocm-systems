* Reduced the cost of the GPU Direct RDMA flush fence (`RCCL_GDR_FLUSH_GPU_MEM_NO_RELAXED_ORDERING`, default `1`) in the `IB` transport on hosts that use peermem. Since the flush scratchpad was registered through peermem, multi-node `ncclReduceScatter` and `ncclAllReduce` lost bus bandwidth from 8 MB to 128 MB, for example on 2 nodes of 8 MI300X. The scratchpad RDMA write of each flush is now posted inline, so the NIC no longer reads its payload from host memory before issuing it. The fence itself is unchanged.
