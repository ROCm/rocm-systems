* Host-hierarchical AllReduce, controlled by `RCCL_HOST_HIER_ALLREDUCE`: a ReduceScatter within each physical host, an AllReduce across hosts, and an AllGather within each host, on communicators split by host hash. By default (`-1`) it is used on gfx1250 when every rank is in one MNNVL clique and the communicator set up DDA fabric (communicators made by `ncclCommSplit` do not), for FP32 sum AllReduce on buffers outside registered windows, with eight ranks per host on two, four or eight hosts, at the message sizes where it measured faster than the default path. `1` enables it for every eligible AllReduce and `0` disables it. It reports as `HierAR` through `rcclGetAlgoName()` (new `rcclAddonAlgos_t` value `RCCL_HOST_HIER_ALLREDUCE`).
