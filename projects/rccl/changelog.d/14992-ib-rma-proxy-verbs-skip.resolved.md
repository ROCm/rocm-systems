* Fixed a crash in communicator initialization on MI455 (gfx1250) hosts where NET runs IB-CAST, on rdma-core stacks (ionic, bng_re) that fault in a second `ibv_get_device_list`. With `NCCL_GIN_TYPE` unset or set to `7` (Anvil SDMA), the IB RMA proxy enumerated the verbs devices again after NET/IB-CAST had. It now skips verbs initialization in those cases. It still initializes when `RCCL_GIN_TYPE_LIST` names proxy GIN (`2`), which runs on the IB RMA proxy, and when IB-CAST stopped before listing the verbs devices, for example because libionic is missing. The socket RMA proxy is not supported on AMD GPUs, so when the skip applies no RMA plugin loads: proxy GIN is unavailable, and host RMA works only when every rank is in one scale-up team. Setting `NCCL_NET=IB-CAST` keeps both, because RMA then uses the IB-CAST RMA proxy, which shares the IB-CAST verbs device list. Other architectures, and gfx1250 hosts on any other NET transport, still initialize the IB RMA proxy.
