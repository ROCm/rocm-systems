********************
RCCL primitive tests
********************

The RCCL Primitive Test (``rccl_prim_test``) is designed to benchmark the performance of individual primitive operations that form the building blocks of RCCL's collective algorithms. 
It allows precise measurement of data transfer performance between GPUs, helping to identify bottlenecks and validate optimizations.
