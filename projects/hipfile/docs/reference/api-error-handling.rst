============================
Error handling API reference
============================

*Declared in:* ``include/hipfile.h``

This page documents the hipFile error handling types, function, and helper macros. hipFile functions use two error-return patterns described in :ref:`error-return-patterns` below.

For the file handle, buffer registration, and IO functions that produce these errors, see :doc:`/reference/api-file-handle-and-buffer`.

``HIPFILE_BASE_ERR``
********************

The base value for hipFile error codes. All ``hipFileOpError_t`` values (except ``hipFileSuccess``) are offsets from this constant.

.. code-block:: c

   #define HIPFILE_BASE_ERR 5000

``hipFileOpError_t``
********************

Return codes from hipFile operations. An error code of ``-1`` indicates that a C or POSIX error has occurred and ``errno`` is likely to have been set.

.. note::

   Values ``HIPFILE_BASE_ERR + 21`` (5021) and ``HIPFILE_BASE_ERR + 32`` (5032) are intentionally omitted from the enumeration.

``hipFileError_t``
******************

Error status returned from most hipFile API calls. The struct carries two fields so that both hipFile-specific errors and GPU driver errors can be communicated in a single return value.

.. code-block:: c

   typedef struct __HIPFILE_NODISCARD hipFileError {
       hipFileOpError_t err;         // Errors related to hipFile or the GPU IO driver
       hipError_t       hip_drv_err; // Errors related to the GPU driver
   } hipFileError_t;

``err``
   A ``hipFileOpError_t`` value describing the hipFile or GPU IO driver error. Check this field against ``hipFileSuccess``.

``hip_drv_err``
   A ``hipError_t`` value from the HIP runtime. When ``err`` equals ``hipFileHipDriverError``, inspect this field for the specific GPU driver error. Otherwise this field is set to ``hipSuccess``.

.. note::

   This struct has the ``[[nodiscard]]`` attribute when compiled with C++ 17 or later, or C23 or later, so unhandled return values generate compiler warnings.

``hipFileGetOpErrorString``
***************************

Return a descriptive string for a hipFile error.

.. code-block:: c

   const char *hipFileGetOpErrorString(hipFileOpError_t status);

:param status: Return code provided by hipFile.
:returns: A human-readable description of the error encountered.

Helper macros
*************

``IS_HIPFILE_ERR``
------------------

Determine if an error code is a hipFile error (that is, its absolute value exceeds ``HIPFILE_BASE_ERR``).

.. code-block:: c

   #define IS_HIPFILE_ERR(hip_op_err) (abs(hip_op_err) > HIPFILE_BASE_ERR)

:param hip_op_err: A ``hipFileOpError_t`` value.
:returns: ``true`` if the value represents a hipFile error, ``false`` otherwise.

``HIPFILE_ERRSTR``
------------------

Get a human-readable error string for a hipFile error. This macro calls ``hipFileGetOpErrorString`` on the absolute value of its argument.

.. code-block:: c

   #define HIPFILE_ERRSTR(hip_op_err) hipFileGetOpErrorString((hipFileOpError_t)abs(hip_op_err))

:param hip_op_err: A ``hipFileOpError_t`` value.
:returns: A string description of the hipFile error.

``IS_HIP_DRV_ERR``
------------------

Determine if a ``hipFileError_t`` represents a GPU driver error (that is, ``err == hipFileHipDriverError``).

.. code-block:: c

   #define IS_HIP_DRV_ERR(hip_err) (hip_err.err == hipFileHipDriverError)

:param hip_err: A ``hipFileError_t`` struct.
:returns: ``true`` if the error originated from the GPU driver, ``false`` otherwise.

``HIP_DRV_ERR``
---------------

Extract the ``hipError_t`` component from a ``hipFileError_t``.

.. code-block:: c

   #define HIP_DRV_ERR(hip_err) (hip_err.hip_drv_err)

:param hip_err: A ``hipFileError_t`` struct.
:returns: The ``hipError_t`` component of the error.

.. _error-return-patterns:

Error return patterns
*********************

hipFile functions follow one of two error-return conventions.

``hipFileError_t`` return (most functions)
------------------------------------------

Most hipFile API functions return a ``hipFileError_t`` struct. To check for success:

#. Verify that ``err`` equals ``hipFileSuccess``.
#. If ``err`` equals ``hipFileHipDriverError``, inspect ``hip_drv_err`` for the specific GPU driver error.

The ``IS_HIPFILE_ERR``, ``HIPFILE_ERRSTR``, ``IS_HIP_DRV_ERR``, and ``HIP_DRV_ERR`` macros simplify these checks.

``ssize_t`` negative return (``hipFileRead`` and ``hipFileWrite``)
------------------------------------------------------------------

``hipFileRead`` and ``hipFileWrite`` return an ``ssize_t`` value:

* **Non-negative**: the number of bytes transferred.
* **-1**: a system error occurred; check ``errno`` for details.
* **Other negative value**: the negative of the ``hipFileOpError_t`` or ``hipError_t`` value that describes the failure. Use ``IS_HIPFILE_ERR`` and ``HIPFILE_ERRSTR`` on the absolute value to classify and stringify the error.

For the full signatures of these IO functions, see :doc:`/reference/api-file-handle-and-buffer`.
