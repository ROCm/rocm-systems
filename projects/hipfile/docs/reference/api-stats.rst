===================================
Statistics collection API reference
===================================

The statistics collection API is an internal interface used by the ``ais-stats``
command-line tool to attach to a running process, collect hipFile IO statistics,
and produce a formatted report. Statistics recording inside the target process is
controlled by the ``HIPFILE_STATS_LEVEL`` environment variable.

For a practical walkthrough of collecting IO statistics, see
:doc:`/how-to/collect-io-statistics`.

*Declared in:* ``src/amd_detail/include_internal/hipfile-stats.h``

.. note::

   This is an internal API co-distributed with hipFile. It is not part of the
   public hipFile surface declared in ``include/hipfile.h``.

Types
*****

``hipFileStatsContext_t``
-------------------------

Opaque pointer to a statistics collection context.

.. code-block:: c

   typedef struct hipFileStatsContext hipFileStatsContext_t;

A context is created with ``hipFileStatsCreateContext`` and freed with
``hipFileStatsCloseContext``. It holds the state needed to communicate with a
target process and to generate a report.

``hipFileStatsError_t``
-----------------------

Error codes returned by statistics collection API functions.

.. code-block:: c

   typedef enum hipFileStatsError {
       hipFileStatsSuccess,
       hipFileStatsInvalidArgument,
       hipFileStatsTargetProcessNotFound,
       hipFileStatsTargetProcessNotAccessible,
       hipFileStatsReportGenerationFailed,
   } hipFileStatsError_t;

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Value
     - Meaning
   * - ``hipFileStatsSuccess``
     - Operation completed successfully.
   * - ``hipFileStatsInvalidArgument``
     - Invalid argument passed to function.
   * - ``hipFileStatsTargetProcessNotFound``
     - Target process with the given PID was not found.
   * - ``hipFileStatsTargetProcessNotAccessible``
     - Cannot access the target process.
   * - ``hipFileStatsReportGenerationFailed``
     - Failed to generate or write the report.

Functions
*********

``hipFileStatsCreateContext``
-----------------------------

Create a new statistics collection context for a target process.

.. code-block:: c

   HIPFILE_API hipFileStatsError_t hipFileStatsCreateContext(hipFileStatsContext_t **context, int targetPid);

:param context: Pointer to store the created context handle.
:param targetPid: Process ID of the target process to monitor.
:returns: ``hipFileStatsSuccess`` on success, or an error code otherwise.

The returned context must be freed with ``hipFileStatsCloseContext``.

``hipFileStatsCloseContext``
----------------------------

Close and free a statistics collection context.

.. code-block:: c

   HIPFILE_API void hipFileStatsCloseContext(hipFileStatsContext_t *context);

:param context: Stats context handle to close. Passing ``NULL`` is safe.

Releases all resources associated with *context*.

``hipFileStatsConnectToTargetProcess``
--------------------------------------

Establish a connection to the target process for statistics collection.

.. code-block:: c

   HIPFILE_API hipFileStatsError_t hipFileStatsConnectToTargetProcess(hipFileStatsContext_t *context);

:param context: Stats context handle.
:returns: ``hipFileStatsSuccess`` on success, or an error code otherwise.

This function must be called before ``hipFileStatsGenerateReport``.

``hipFileStatsPollTargetProcess``
---------------------------------

Poll the target process for completion.

.. code-block:: c

   HIPFILE_API hipFileStatsError_t hipFileStatsPollTargetProcess(const hipFileStatsContext_t *context,
                                                                 bool                         block);

:param context: Stats context handle.
:param block: When ``true``, block until the target process completes. When ``false``, return immediately.
:returns: ``hipFileStatsSuccess`` on success, or an error code otherwise.

``hipFileStatsGenerateReport``
------------------------------

Generate a formatted statistics report and write it to a file descriptor.

.. code-block:: c

   HIPFILE_API hipFileStatsError_t hipFileStatsGenerateReport(const hipFileStatsContext_t *context, int fd);

:param context: Stats context handle.
:param fd: File descriptor to write the report to.
:returns: ``hipFileStatsSuccess`` on success, or an error code otherwise.

Environment variable
********************

``HIPFILE_STATS_LEVEL``
-----------------------

Controls the level of detail for statistics collection in the target process.

.. list-table::
   :header-rows: 1
   :widths: 15 85

   * - Value
     - Description
   * - ``0``
     - Disabled.
   * - ``1``
     - Basic statistics (default when statistics are enabled).
   * - ``2``
     - Detailed (reserved for future use; currently identical to basic).

Set this variable in the target process's environment before it begins hipFile
IO operations. For more details on environment variables, see
:doc:`/conceptual/environment-variables`.
