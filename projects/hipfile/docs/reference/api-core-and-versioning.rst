=================================
Core and versioning API reference
=================================

This page documents the hipFile core API surface: compile-time version macros, a runtime version query function, the platform-independent offset type, and typed getter and setter functions for library configuration parameters.

For driver initialization and shutdown functions, see :doc:`/reference/api-driver-lifecycle`.

Platform-independent offset type
********************************

*Declared in:* ``include/hipfile.h``

``hoff_t``
   Platform-independent signed offset type used for file and buffer offsets throughout the hipFile API.

   .. code-block:: c

      #ifdef _WIN32
      typedef __int64 hoff_t;
      #else
      typedef off_t hoff_t;
      #endif

Version macros
**************

*Declared in:* ``include/hipfile.h``

hipFile uses `semantic versioning <https://semver.org/>`_. The following macros are set to integer values and can be used in preprocessor conditionals to handle API differences across releases.

``HIPFILE_VERSION_MAJOR``
   hipFile major version number. Currently defined as ``0``.

   .. code-block:: c

      #define HIPFILE_VERSION_MAJOR 0

``HIPFILE_VERSION_MINOR``
   hipFile minor version number. Currently defined as ``2``.

   .. code-block:: c

      #define HIPFILE_VERSION_MINOR 2

``HIPFILE_VERSION_PATCH``
   hipFile patch version number. Currently defined as ``0``.

   .. code-block:: c

      #define HIPFILE_VERSION_PATCH 0

Runtime version query
*********************

*Declared in:* ``include/hipfile.h``

``hipFileGetVersion``
   Get the version of the hipFile library at runtime.

   .. code-block:: c

      HIPFILE_API hipFileError_t hipFileGetVersion(unsigned *major, unsigned *minor, unsigned *patch);

   :param major: The major version.
   :param minor: The minor version.
   :param patch: The patch version.
   :returns: ``hipFileError_t`` indicating success or failure.

   .. note::

      Any parameter can be set to ``NULL`` to ignore that part of the version.

Configuration parameter getter functions
****************************************

*Declared in:* ``include/hipfile.h``

.. warning::

   All parameter getter functions are currently unimplemented and return errors when called.

When the driver is open, these functions return the value currently in use by the driver. When the driver is closed, they return the value that was last set by the corresponding ``hipFileSetParameter*`` function.

``hipFileGetParameterSizeT``
   Get the value of a ``size_t`` configuration parameter.

   .. code-block:: c

      HIPFILE_API hipFileError_t hipFileGetParameterSizeT(hipFileSizeTConfigParameter_t param, size_t *value);

   :param param: The configuration parameter.
   :param value: The location to store the value of the configuration parameter.
   :returns: ``hipFileError_t`` indicating success or failure.

``hipFileGetParameterBool``
   Get the value of a Boolean configuration parameter.

   .. code-block:: c

      HIPFILE_API hipFileError_t hipFileGetParameterBool(hipFileBoolConfigParameter_t param, bool *value);

   :param param: The configuration parameter.
   :param value: The location to store the value of the configuration parameter.
   :returns: ``hipFileError_t`` indicating success or failure.

``hipFileGetParameterString``
   Get the value of a string configuration parameter.

   .. code-block:: c

      HIPFILE_API hipFileError_t hipFileGetParameterString(hipFileStringConfigParameter_t param, char *desc_str, int len);

   :param param: The configuration parameter.
   :param desc_str: The location to store the value of the configuration parameter.
   :param len: The length of the ``desc_str`` buffer.
   :returns: ``hipFileError_t`` indicating success or failure.

****************************************

*Declared in:* ``include/hipfile.h``
