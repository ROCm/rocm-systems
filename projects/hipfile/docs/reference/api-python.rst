====================
Python API reference
====================

The ``hipfile`` Python package provides Cython-backed bindings for the hipFile
C library. The public surface consists of context-manager classes for driver
lifecycle, file registration, and buffer registration; enumerations mirroring
the C error and handle-type enums; an exception type that wraps both error
fields; and module-level query functions.

For a guided walkthrough of the Python bindings, see
:doc:`/how-to/use-python-api`. For a complete copy-file example, see
:doc:`/tutorials/python-file-copy`.

*Declared in:* ``python/hipfile/__init__.py``

The package exports the following symbols through ``__all__``:

- ``Driver``
- ``FileHandle``
- ``Buffer``
- ``HipFileException``
- ``FileHandleType``
- ``OpError``
- ``driver_get_properties``
- ``get_version``
- ``__version__``

``__version__`` is a string of the form ``"MAJOR.MINOR.PATCH"`` derived from
the compile-time constants ``VERSION_MAJOR``, ``VERSION_MINOR``, and
``VERSION_PATCH``.

Classes

``Driver``
----------

*Declared in:* ``python/hipfile/driver.py``

Manages the hipFile driver lifecycle. The driver is reference-counted
internally; multiple ``open`` calls are balanced by an equal number of
``close`` calls. ``Driver`` supports the context-manager protocol for
automatic ``open`` and ``close``.

``Driver.open``
^^^^^^^^^^^^^^^

   Open the hipFile driver.

   .. code-block:: python

      def open(self) -> None

   :raises HipFileException: If the open call fails.

``Driver.close``
^^^^^^^^^^^^^^^^

   Close the hipFile driver.

   .. code-block:: python

      def close(self) -> None

   :raises HipFileException: If the close call fails.

``Driver.use_count``
^^^^^^^^^^^^^^^^^^^^

   Return the current driver reference count. This is a static method.

   .. code-block:: python

      @staticmethod
      def use_count() -> int

   :returns: The driver reference count.

Context-manager protocol
^^^^^^^^^^^^^^^^^^^^^^^^

   ``__enter__`` calls ``open`` and returns the ``Driver`` instance.
   ``__exit__`` calls ``close``.


``FileHandle``
--------------

*Declared in:* ``python/hipfile/file.py``

Manages a file descriptor registered with the hipFile driver. Wraps
``os.open`` and ``os.close`` together with hipFile handle registration so that
GPU-accelerated reads and writes can be performed through a single object.
Supports the context-manager protocol for automatic ``open`` and ``close``.

Constructor
^^^^^^^^^^^

   .. code-block:: python

      def __init__(
          self,
          path: str | os.PathLike[str],
          flags: int,
          mode: int = DEFAULT_MODE,
          handle_type: FileHandleType = FileHandleType.OPAQUE_FD,
      ) -> None

   The file is **not** opened until ``open`` is called or the context manager
   is entered.

   :param path: Filesystem path to open.
   :param flags: Flags passed to ``os.open`` (for example ``os.O_RDONLY | os.O_DIRECT``).
   :param mode: Permission bits used when creating a file. Defaults to ``0o644``
       (``stat.S_IRUSR | stat.S_IWUSR | stat.S_IRGRP | stat.S_IROTH``).
   :param handle_type: Type of handle to register. Defaults to
       ``FileHandleType.OPAQUE_FD``.

``FileHandle.open``
^^^^^^^^^^^^^^^^^^^

   Open the file and register it with the hipFile driver.

   .. code-block:: python

      def open(self) -> None

   :raises RuntimeError: If the file handle is already open.
   :raises HipFileException: If hipFile handle registration fails.

``FileHandle.close``
^^^^^^^^^^^^^^^^^^^^

   Deregister the hipFile handle and close the file descriptor. Safe to call
   multiple times; subsequent calls are no-ops.

   .. code-block:: python

      def close(self) -> None

``FileHandle.read``
^^^^^^^^^^^^^^^^^^^

   Read from the file into a GPU buffer.

   .. code-block:: python

      def read(
          self, buffer: Buffer, size: int, file_offset: int, buffer_offset: int
      ) -> int

   :param buffer: GPU buffer to read into.
   :param size: Number of bytes to read.
   :param file_offset: Byte offset within the file to start reading from.
   :param buffer_offset: Byte offset within the GPU buffer to read into.
   :returns: Number of bytes actually read.
   :raises RuntimeError: If the file handle is not open.
   :raises OSError: On a system-level IO error (wraps ``errno``).
   :raises HipFileException: On a hipFile or HIP driver error.

``FileHandle.write``
^^^^^^^^^^^^^^^^^^^^

   Write from a GPU buffer into the file.

   .. code-block:: python

      def write(
          self, buffer: Buffer, size: int, file_offset: int, buffer_offset: int
      ) -> int

   :param buffer: GPU buffer to write from.
   :param size: Number of bytes to write.
   :param file_offset: Byte offset within the file to start writing to.
   :param buffer_offset: Byte offset within the GPU buffer to write from.
   :returns: Number of bytes actually written.
   :raises RuntimeError: If the file handle is not open.
   :raises OSError: On a system-level IO error (wraps ``errno``).
   :raises HipFileException: On a hipFile or HIP driver error.

Properties
^^^^^^^^^^

``path``
   Filesystem path (``str | os.PathLike[str]``).

``flags``
   Flags passed to ``os.open`` (``int``).

``mode``
   File creation permission bits (``int``).

``handle``
   Opaque hipFile handle, or ``None`` if not open (``int | None``).

``handle_type``
   Handle type used for registration (``FileHandleType | None``). Setting this
   property while the handle is open raises ``RuntimeError``. Setting it to
   ``OPAQUE_WIN32`` raises ``NotImplementedError``. Setting it to a value that
   is not a ``FileHandleType`` member raises ``ValueError``.

Context-manager protocol
^^^^^^^^^^^^^^^^^^^^^^^^

   ``__enter__`` calls ``open`` and returns the ``FileHandle`` instance.
   ``__exit__`` calls ``close``.


``Buffer``
----------

*Declared in:* ``python/hipfile/buffer.py``

Manages registration of a GPU memory buffer with hipFile. ``Buffer`` does
**not** own the underlying GPU allocation; it only manages the hipFile
registration lifetime. Supports the context-manager protocol for automatic
``register`` and ``deregister``.

Constructor
^^^^^^^^^^^

   .. code-block:: python

      def __init__(self, buffer_ptr: int, length: int, flags: int) -> None

   :param buffer_ptr: Integer address of the GPU memory.
   :param length: Size of the buffer in bytes.
   :param flags: Registration flags (pass ``0`` for default behavior).

``Buffer.from_ctypes_void_p``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

   Class method. Create a ``Buffer`` from a ``ctypes.c_void_p``.

   .. code-block:: python

      @classmethod
      def from_ctypes_void_p(
          cls, ctypes_void_p: c_void_p, length: int, flags: int
      ) -> Buffer

   :param ctypes_void_p: Pointer to GPU memory. Must not be null.
   :param length: Size of the buffer in bytes.
   :param flags: Registration flags (pass ``0`` for default behavior).
   :raises ValueError: If *ctypes_void_p* is null.

``Buffer.register``
^^^^^^^^^^^^^^^^^^^

   Register the buffer with the hipFile driver.

   .. code-block:: python

      def register(self) -> None

   :raises HipFileException: If the registration call fails.

``Buffer.deregister``
^^^^^^^^^^^^^^^^^^^^^

   Deregister the buffer from the hipFile driver. This is a no-op if the
   buffer is not currently registered.

   .. code-block:: python

      def deregister(self) -> None

   :raises HipFileException: If the deregistration call fails.

``ptr`` property
^^^^^^^^^^^^^^^^

   Integer address of the GPU memory (``int``).

Context-manager protocol
^^^^^^^^^^^^^^^^^^^^^^^^

   ``__enter__`` calls ``register`` and returns the ``Buffer`` instance.
   ``__exit__`` calls ``deregister``.

``HipFileException``
--------------------

*Declared in:* ``python/hipfile/error.py``

Raised when a hipFile operation fails. Wraps both the ``hipFileOpError_t``
code and, when the error is ``OpError.HIP_DRIVER_ERROR``, the underlying
``hipError_t`` from the HIP runtime.

Constructor
^^^^^^^^^^^

   .. code-block:: python

      def __init__(self, hipfile_err: int, hip_err: int) -> None

   :param hipfile_err: ``hipFileOpError_t`` value describing the failure.
   :param hip_err: ``hipError_t`` value from the HIP runtime. Only meaningful
       when *hipfile_err* equals ``OpError.HIP_DRIVER_ERROR``.

``hipfile_err`` property
^^^^^^^^^^^^^^^^^^^^^^^^

   ``hipFileOpError_t`` code for this error (``int``).

``hip_err`` property
^^^^^^^^^^^^^^^^^^^^

   ``hipError_t`` code from the HIP runtime (``int``). Only meaningful when
   ``hipfile_err`` equals ``OpError.HIP_DRIVER_ERROR``.

``__str__``
^^^^^^^^^^^

   Returns a human-readable description of the error. When the error is
   ``OpError.HIP_DRIVER_ERROR``, the HIP error code is appended to the
   string.

Provisional GPU memory helpers
******************************

*Declared in:* ``python/hipfile/hipMalloc.py``

The ``hipfile.hipMalloc`` module exposes ``hipMalloc`` and ``hipFree`` as thin
``ctypes`` wrappers around the HIP runtime. These helpers are provisional and
exist to provide basic GPU memory management without introducing extra
dependencies. Do not rely on their signatures or continued availability.
