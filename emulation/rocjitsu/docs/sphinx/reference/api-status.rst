==========================================
Status codes and compiler macros reference
==========================================

Status codes returned by all rocJITsu C API functions and compiler portability
macros for shared-library symbol export and diagnostic suppression.  These
definitions are consumed by the :doc:`/reference/api-vm` and
:doc:`/reference/api-code-object` APIs.

Status codes
************

.. doxygenenum:: rj_status_e

Compiler macros
***************

Symbol export
-------------

.. c:macro:: RJ_API_EXPORT

   Marks a function or variable as part of the rocJITsu public ABI.

   On Windows, expands to ``__declspec(dllexport)`` (or ``__declspec(dllimport)``
   when consuming the library). On GCC and Clang, expands to
   ``__attribute__((visibility("default")))``.

Diagnostic suppression
----------------------

.. c:macro:: RJ_DIAGNOSTIC_PUSH

   Saves the current compiler diagnostic state. Pair with
   :c:macro:`RJ_DIAGNOSTIC_POP`.

.. c:macro:: RJ_DIAGNOSTIC_POP

   Restores the diagnostic state saved by :c:macro:`RJ_DIAGNOSTIC_PUSH`.

.. c:macro:: RJ_DIAGNOSTIC_IGNORE_PEDANTIC

   Suppresses ``-Wpedantic`` (GCC/Clang) or warning C4200 (MSVC).

.. c:macro:: RJ_DIAGNOSTIC_IGNORE_NONNULL_COMPARE

   Suppresses ``-Wnonnull-compare`` (GCC) or ``-Wpointer-bool-conversion``
   (Clang). No-op on MSVC.

.. c:macro:: RJ_DIAGNOSTIC_IGNORE_CLOBBERED

   Suppresses ``-Wclobbered`` (GCC). No-op on Clang and MSVC.
