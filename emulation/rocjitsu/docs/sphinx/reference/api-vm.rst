=============================
Virtual machine API reference
=============================

The virtual machine API creates, configures, runs, checkpoints, and tears down
the rocJITsu GPU virtual machine. It supports both local (in-process) and
daemon (multi-process) modes, device memory mapping, GPU metadata queries,
and clean shutdown.

For the design rationale behind the virtual machine, see
:doc:`/conceptual/gpu-vm-design`. For JSON configuration options that
control VM topology and simulation parameters, see
:doc:`/conceptual/json-configuration`.
