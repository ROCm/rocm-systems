=========================================
Code object and instruction API reference
=========================================

The rocJITsu code object and instruction API lets you load executables and
code objects, decode and disassemble instructions, build basic-block lists,
and invoke the dynamic binary translator to convert code objects between GPU
ISA pairs. For architectural context, see :doc:`/conceptual/architecture`.
For a guided walkthrough, see :doc:`/tutorials/inspect-code-object`.

All functions return :doc:`rj_status_t </reference/api-status>` status codes
unless otherwise noted.

Reference-count lifecycle
*************************

All opaque handles in this API follow a consistent reference-count protocol:

- ``_create`` functions produce a handle with an initial reference count of 0,
  except ``rj_code_executable_get_code_object`` and
  ``rj_code_basic_block_list_get``, which produce handles with a reference
  count of 1.
- ``_retain`` increments the reference count.
- ``_release`` decrements the reference count. If the handle has been
  destroyed and the count reaches 0, the backing memory is freed.
- ``_destroy`` marks the handle for destruction. If the reference count is
  already 0, the memory is freed immediately; otherwise it is freed when the
  last ``_release`` drops the count to 0.

Passing ``NULL`` to any ``_retain``, ``_release``, or ``_destroy`` function is
a no-op.
