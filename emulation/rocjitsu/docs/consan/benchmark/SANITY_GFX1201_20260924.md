# RDNA4 sanity check after atomic publication changes

September 24, 2026, gfx1201 / Radeon RX 9070. This is a targeted regression
check, not a replacement benchmark campaign. The historical timing table stays
unchanged. Its `/tmp/consan-benchmark-gfx1201-refresh-fixed` artifacts no longer
exist, so comparisons with that table cannot isolate source changes from changes
in the ROCm/PyTorch stack or measurement variation.

## Regression found and fixed

The Gluon shared-memory round trip passed natively but failed under Default
with `HSA_STATUS_ERROR_ILLEGAL_INSTRUCTION`. Its final ISA retained an
`s_clause` covering ordinary global stores while the new publication capture
inserted arithmetic into the clause. That path has no synchronization sequence,
so it bypassed the sequence-based clause rewrite.

Commit `ac6019b08d6` looks up the enclosing clause from the decoded control flow
for every captured modification. It reuses the existing deduplicated NOP rewrite.
The Gluon workload subsequently passed Default, high, and SuperCollider, with
complete static and dynamic coverage and a passing numerical oracle. A new
lowering test covers two ordinary stores in one clause without a release/acquire
sequence. The ConSan suite passed 975 tests; two opt-in benchmark tests skipped.

## Performance checks

All checks used the benchmark runner's native rocprofv3 discovery and generated
exact kernel allowlists, numerical oracles, static coverage audit, and final
native drift check. GPU workloads ran serially. Detailed measurements and the
validation results are retained in the artifact root below.

Initial dense decode: native 2.72 ms (historical 2.67 ms); Default 5.79 ms
(7.04 ms); high 13.3 ms (10.2 ms); SuperCollider 5.03 ms (3.87 ms).
This initial run preceded the clause fix. Startup was 86.6/86.7/56.1 seconds
versus the historical 198/198/155 seconds.

After the fix, Gluon: native 94.2 µs (180 µs); Default 290 µs (217 µs);
high 264 µs (198 µs); SuperCollider 159 µs (175 µs). Startup stayed around
0.46 seconds. The Default latency increase is visible even though the absolute
cost remains below 0.3 ms; changed native latency makes the slowdown ratios
particularly unsuitable for attributing a regression to these commits.

After the fix, hipBLASLt: native 12.8 µs (9.48 µs); Default 110 µs (89.5 µs);
high 763 µs (733 µs); SuperCollider 37.9 µs (26.0 µs). Startup was
0.625/0.605/0.436 seconds versus 0.897/0.886/0.570 seconds. The client requires
its matching `therock_venv` libraries and profiler: using the newer validation
ROCm libraries failed native discovery with an incompatible Origami symbol.

The initial decode, fixed Gluon, and matched hipBLASLt runs had final native
Run drift of +3.2%, +1.9%, and +1.8%, respectively. All nine admitted
instrumented cells reported complete coverage and zero conflicts.
