# Physical gfx950 campaign

The thirteen-row MI350X campaign is reported in [STATUS_GFX950.md](STATUS_GFX950.md).
Its measurements follow [BENCHMARK.md](BENCHMARK.md), including the independent
numerical oracle, two synchronized operations, native `rocprofv3` kernel discovery,
and unchanged exact-name allowlists for all four ConSan modes.

## Prepared host

The campaign uses the physical MI350X at PCI `0000:83:00.0`, with 256 CUs,
and the TheRock SDK installed in `/home/benjacob/.venv`. It uses Python 3.10,
TheRock `10.2.0a20260914`, HIP `7.16.26366`, PyTorch
`2.13.0+rocm10.2.0a20260914`, and TokenSpeed kernel
`0.1.3.dev20260914+gita0cc3bb4`. TokenSpeed's own Triton package is
`3.8.10.post20260906`. Each cell records its runtime and source identities;
those records are authoritative for that measurement.

Activate `/home/benjacob/consan-prerequisites/env.sh` to select this SDK,
its profiler and libraries, and the built ConSan hook. The prerequisite
README, constraints, source revisions, compiler setup, and smoke-test evidence
are under `/home/benjacob/consan-prerequisites/`. No system `/opt` ROCm stack
or emulated GPU is used for these measurements.

From `/home/benjacob/rocm-systems/emulation/rocjitsu`:

```sh
source /home/benjacob/consan-prerequisites/env.sh
python tests/dbi/consan/consan_benchmark.py \
  --target gfx950 \
  --python /home/benjacob/.venv/bin/python \
  --aorta-dir /home/benjacob/aorta \
  --hook "$CONSAN_HOOK" \
  --rocprofv3 "$ROCM_PATH/bin/rocprofv3" \
  --hipblaslt-bench "$HIPBLASLT_BENCH" \
  --qwen-model /home/benjacob/consan-prerequisites/models/Qwen3-0.6B \
  --output-dir /home/benjacob/consan-gfx950-benchmark-full \
  --status docs/consan/benchmark/STATUS_GFX950.md \
  --timeout 600 --resume
```

Use a new output directory for an independent campaign. The runner updates the
preallocated status table as each cell runs or finishes. GPU cells execute
serially; the 600-second limit applies to each process, not the entire suite.

## Evidence and retained measurements

The output directory contains native profiler traces, generated allowlists,
per-cell JSON checkpoints and logs, and live progress. Successful instrumented
cells include numerical results and a static instrumentation audit. A dynamic
analysis limitation is recorded separately under the benchmark contract.

Completed measurements were retained across local ConSan fixes at the user's
request. Their checkpoint `provenance` retains the actual source and hook used;
`reuse_decision` records compatibility decisions and archived checkpoints.
Compatibility fingerprints used to resume the campaign do not relabel the
measured executable. Retention manifests in the output directory document these
transitions. Archived hook binaries are under `executable-artifacts/`.

The campaign is incomplete while the status table contains pending, running, or
failed cells. `completed-cell-audit.json` checks only completed cells and is not
an assertion that the full matrix has finished. Final review must cover all
thirteen rows, including the final native drift check for each workload.

### Remaining-row mode selection

Run all four modes for the remaining rows with `--timeout 600 --resume`.
The owner superseded the temporary InlineShadow skip directive: InlineShadow
failures remain recorded while the rest of the matrix completes, then receive
a debugging pass. The standard `consan_benchmark.py` driver is used again.
Retain completed measurements; a timeout remains distinct from a failure.

The Qwen prefill ModelRunner retained HSA through process exit, leaving no
`OnUnload` analysis verdict despite passing its numerical oracle. Commit
`59c1851880` adds process-exit report finalization with idempotent unload.
The host regression reproduces the missing verdict before the fix; all 127
ConSan hook tests pass afterward, including repeated-unload coverage.
Completed measurements keep their original provenance in
`exit-finalization-retention.json`; the affected Qwen cell is rerun.

The physical rerun exposed a later HIP exit handler invoking cached tool
callbacks after finalization. Commit `7bc055df13` retains the layer and original
runtime functions for those callbacks. A second exit regression reproduces
the failure and passes after the fix; all 128 ConSan hook tests pass. The
interrupted Qwen attempt's numerical result and complete 934/934 verdict are
saved as diagnostic evidence, and the normal benchmark cell is rerun.
