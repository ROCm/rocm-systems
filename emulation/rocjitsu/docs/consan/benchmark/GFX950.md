# Physical gfx950 campaign

The thirteen-workload MI350X campaign is reported live in
[STATUS_GFX950.md](STATUS_GFX950.md). This is a fresh September 17, 2026
reevaluation, not a reuse of the previous campaign's numbers.

Columns follow this order: Uninstrumented, Default Mode, Default Mode
(`RJ_CONSAN_PRESET=high`), and SuperCollider. Each has Startup and Run values.
The two Default Mode variants explicitly use the default and high presets;
the high preset is not a separate sanitizer mode.

## Invocation and live results

```sh
bash /home/benjacob/work/consan-benchmark-prerequisites/run-gfx950.sh
```

That script selects the venv SDK and optimized GCC-built hook, holds
`/tmp/rocm-physical-gpu.lock` for the entire campaign, and runs the benchmark
with `--resume` and a 1,800-second per-process timeout. Each cell runs in a
fresh process; all physical GPU work is serialized. The source, hook, inputs,
commands, controlled environment, and package identities are recorded in the
fingerprinted artifacts. Markdown ledger edits do not invalidate checkpoints.

The fresh output directory is
`/home/benjacob/work/consan-benchmark-gfx950-20260917/`.
The runner updates the status table on each cell's start and completion.
Failed cells remain visibly failed; they are not admitted as measurements.
The campaign log is
`/home/benjacob/work/consan-benchmark-prerequisites/campaign.log`.

## Measurement and acceptance

The contract in [BENCHMARK.md](BENCHMARK.md) is unchanged: native profiler
discovery, an exact-name kernel allowlist, two native baseline processes,
correctness-checked instrumented variants, and a final native drift check.
Each process performs two identical synchronized operations; the first
includes selected host analysis, while the second measures sustainable device
instrumentation without repeating that analysis.

Numerical correctness and complete static instrumentation gate admission.
Dynamic race reports and bounded evidence-retention limitations remain in
artifacts; accepted performance cells do not establish exhaustive race coverage.
Inapplicable cells must be labeled as such, with no overhead claim.

The initial run exposed a parser conflict with ConSan's human-facing coverage
hint. Commit `2be652b683` excludes that exact prose prefix from structured
coverage parsing, preserving fail-closed checks for malformed or missing audit
records. Coverage and benchmark regression suites passed; the affected cells
were invalidated and rerun.

The hipBLASLt client then exposed a missing timing summary in the process-exit
fallback (the summary previously lived only in `OnUnload`). Commit
`b929ec3a63` moves it into shared, once-only finalization. All 200 hook host
tests passed in GCC and UBSan, together with 100 repetitions of each of four
lifecycle/timing tests in both builds. The hook fingerprint changed, so prior
measurements are invalidated rather than silently reused.

### Final host-availability window

At 2026-09-18 01:24 UTC, the remaining host allocation was limited to roughly
30 minutes. The campaign switched to benchmark-only execution: no further
debugging, source fixes, or failed-cell retries. The active TokenSpeed batch
continues first, followed by fresh Aorta dense prefill, synthetic decode, and
top-1 MoE if time permits. The original 01:53 UTC cutoff was extended at the
user's request to 01:56:10 UTC (ten additional minutes from that request),
followed by a final local documentation commit. Missing or
interrupted cells must not be interpreted as passes, and older-hook Aorta
measurements are not substituted into the current matrix.

The medium-M GEMM final native Run was 17.84% faster than its two-process
baseline. Its numerical and instrumentation gates passed, but its overhead
ratios remain subject to this baseline-drift caveat. The limited final window
prioritizes missing measurements over rerunning this row; no baseline is
silently replaced.

Ten of the thirteen workload rows completed all three modes and their final
native check on the current hook. For those rows, final native Run drift was
between -6.58% and +2.23%, except medium-M GEMM (-17.84%, noted above).
The current-hook Aorta synthetic decode row completed Default Mode and
SuperCollider, including its final native check (+2.25% Run drift). High was
explicitly skipped at the user's request. A temporary, external orchestration
wrapper selected only Default Mode (resumed) and SuperCollider, preserving
all three rendered columns and the unchanged runner, fingerprints, numerical
oracles, and static audit gates. Its high process had just started when it
was stopped; no measurement from that interrupted attempt was admitted.
SuperCollider and the final native check subsequently exited successfully.
The Aorta
four-expert top-1 MoE row was not reached in the time-limited rerun. Older-hook
artifacts remain on disk but are not presented as current-hook measurements.

During this window, TokenSpeed BF16 MoE failed its Default Mode static gate:
`verdict applicable=false; verdict static_complete=false; no applicable code
objects`. This is a failed benchmark admission, not an accepted overhead
measurement. The runner stopped that workload before high and SuperCollider;
those modes were not reached. Per the benchmark-only instruction, the failure
was neither debugged nor retried, and execution continued with Aorta workloads.

The final checkpoint at 2026-09-18 01:56 UTC contains 32 accepted instrumented
mode cells, one failed admission, and six unmeasured mode cells. This is a
time-limited result, not a claim that the complete requested matrix finished.
All physical runs were serialized with the shared GPU lock. No further
benchmark runs are queued. The final status document explicitly labels
skipped and unreached cells rather than retaining transient running states.
