The thirteen-workload MI350X campaign is reported live in

reevaluation, not a reuse of the previous campaign's numbers.

## Invocation and live results

```sh
bash /home/benjacob/work/consan-benchmark-prerequisites/run-gfx950.sh
```

That script selects the venv SDK and optimized GCC-built hook, holds
`/tmp/rocm-physical-gpu.lock` for the entire campaign, and runs the benchmark
with `--resume` and a 1,800-second per-process timeout. Each cell runs in a
fresh process; all physical GPU work is serialized. The source, hook, inputs,
commands, controlled environment, and package identities are recorded in the
fingerprinted artifacts. Markdown ledger edits do not invalidate checkpoints.

The fresh output directory is
`/home/benjacob/work/consan-benchmark-gfx950-20260917/`.
The runner updates the status table on each cell's start and completion.
Failed cells remain visibly failed; they are not admitted as measurements.
The campaign log is
`/home/benjacob/work/consan-benchmark-prerequisites/campaign.log`.

## Measurement and acceptance

The contract in [BENCHMARK.md](BENCHMARK.md) is unchanged: native profiler
discovery, an exact-name kernel allowlist, two native baseline processes,
correctness-checked instrumented variants, and a final native drift check.
Each process performs two identical synchronized operations; the first
includes selected host analysis, while the second measures sustainable device
instrumentation without repeating that analysis.

Numerical correctness and complete static instrumentation gate admission.
Dynamic race reports and bounded evidence-retention limitations remain in
artifacts; accepted performance cells do not establish exhaustive race coverage.
Inapplicable cells must be labeled as such, with no overhead claim.

The initial run exposed a parser conflict with ConSan's human-facing coverage
hint. Commit `2be652b683` excludes that exact prose prefix from structured
coverage parsing, preserving fail-closed checks for malformed or missing audit
records. Coverage and benchmark regression suites passed; the affected cells
were invalidated and rerun.

The hipBLASLt client then exposed a missing timing summary in the process-exit
fallback (the summary previously lived only in `OnUnload`). Commit
`b929ec3a63` moves it into shared, once-only finalization. All 200 hook host
tests passed in GCC and UBSan, together with 100 repetitions of each of four
lifecycle/timing tests in both builds. The hook fingerprint changed, so prior
measurements are invalidated rather than silently reused.
