Run policy:

testcase delivery and the deferred forkserver. The host system uses a piped
`core_pattern`, so the wrapper set `AFL_I_DONT_CARE_ABOUT_MISSING_CRASHES=1`.
No crash or hang files were written under any `default/crashes` or
`default/hangs` directory.

Post-campaign validation on 2026-05-24 reran the same seed with branch-only
device instrumentation:

```sh
ROCJITSU_AFL_SKIP_ENTRY_PROBE=1 ROCJITSU_AFL_EDGE_LIMIT=0 \
ROCJITSU_AFL_BRANCH_EDGE_SLOTS=1 ROCJITSU_AFL_REQUIRE_DEVICE_EDGES=1 \
  ./build/rocfuzz_example_rocsparse_spmv seeds/rocsparse_spmv/seed0
```

That run exited successfully and patched two real HSA-reader rocSPARSE payloads
with 249 and 393 edge sites, respectively. The checked-in smoke and AFL wrapper
now treat `rocsparse-spmv` as device-code branch coverage, although the AFL
wrapper still uses the non-persistent binary because deferred-forkserver
persistent mode remains a separate stability issue. The AFL wrapper leaves the
required-device-edge gate off during campaigns to avoid classifying edge-less
mutations as crashes; the CMake smoke remains the required-edge wiring gate.
A 10-second AFL wrapper check after this change found four new corpus items,
reported 17.25% bitmap coverage, and saved no crashes or hangs.
