# ROCm-Systems Scripts

## [abi-guard.py](abi-guard.py)

[abi-guard.py](abi-guard.py) is a Python3 command-line tool for generating/updating the project's VERSION file,
generating a versioning YAML spec, listing the files included or excluded in the API/ABI checks, executing API/ABI checks, etc.

A quick start tutorial on how to use [abi-guard.py](abi-guard.py) are provided in [abi-guard-README.md](abi-guard-README.md).
The Python requirements are located in [abi-guard-requirements.txt](abi-guard-requirements.txt).
