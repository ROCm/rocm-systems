# Find ROCm Systems Examples

This directory contains example applications and usage patterns for find ROCm Systems.

## Available Examples

### test-application/

Example demonstrating how to use `find_package(rocm-systems)` in your CMake projects for specific Component Tests.

**Contents:**
- `CMakeLists.txt` - Example build configuration
- `rocm_info_test.cpp` - Query ROCm version and paths
- `hsa_runtime_test.cpp` - Use HSA Runtime
- `README.md` - Detailed instructions

### findROCMSystems_test/

Example demonstrating how to use `find_package(rocm-systems)` in your CMake projects for finding all components.

**Contents:**
- `CMakeLists.txt` - Example build configuration
- `README.md` - Detailed instructions
